# Augustine Chibueze: portfolio (Miva Open University assignment)

Plain HTML, CSS and vanilla JavaScript. No build step. Open `index.html` or upload the folder as is.

```
index.html      Home: name, photo, welcome message, navigation, brief biography
about.html      Education, career aspirations, technical skills, experience, hobbies, video
projects.html   Five projects with descriptions, screenshots, links and a table
planner.html    Academic planner: add, complete and delete tasks (js/planner.js)
contact.html    Contact form with validation (js/contact.js)
css/styles.css  One external stylesheet (grid, flexbox, responsive, transitions, dark mode)
js/main.js      Shared: theme toggle, menu, scroll effects, preloader
assets/projects/myautoapplier.jpg   MyAutoApplier screenshot
assets/media/intro.mp4              Video shown on the About page
```

## Things to customise

- **Video**: `assets/media/intro.mp4` is a 12 second highlights reel. Replace it (and `intro-poster.jpg`) with your own intro video if you like.
- **Contact form**: with no backend it opens the visitor's email app with the message pre-filled. To receive messages directly, paste a form service URL into `FORM_ENDPOINT` at the top of `js/contact.js`.
- **About page**: the career aspirations and hobbies are drafted from your profile. Edit them to say what is true for you.
- **Company logos**: replace the files in `assets/logos/` (see the table in the old README for names).
